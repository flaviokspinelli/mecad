# MecaCAD

CAD paramétrico desktop voltado a projetos de mecatrônica, com uma experiência
familiar para usuários do Autodesk Fusion 360 e identidade visual própria.

## Objetivo

Construir de forma incremental uma ferramenta acessível para modelagem de peças,
montagens mecatrônicas, desenhos técnicos, fabricação e simulação.

## Direção técnica inicial

- C++ 20
- Qt 6 e QML
- Open CASCADE
- OpenGL
- Formato de projeto próprio
- Windows como primeira plataforma, mantendo portabilidade para macOS e Linux

O escopo e a ordem das entregas estão em [BACKLOG.md](BACKLOG.md).
